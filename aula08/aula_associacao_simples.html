Associação simples entre classes

Um objeto pode guardar uma referência para outro objeto. Vamos representar essa relação em Java, passar a referência pelo construtor e acompanhar a criação dos objetos no código.

1 · Conceito

Uma classe pode conhecer outra

01
Definição

Existe uma associação simples quando uma classe possui um campo cujo tipo é outra classe. Esse campo guarda uma referência para um objeto associado.

A classe que contém o campo pode usar essa referência para consultar dados e chamar métodos do outro objeto.

Exemplo em palavras

Um Pedido tem um Cliente. A classe Pedido declara um atributo cliente do tipo Cliente.

public class Pedido {
    private Cliente cliente;
}
Ideia principal: o campo não guarda uma cópia da classe; guarda uma referência para uma instância.
2 · Passando a referência

O objeto associado chega pelo construtor

02

Crie primeiro o objeto associado. Depois passe sua referência ao construtor do objeto que terá o campo.

Ordem: instanciar → passar a referência → guardar no atributo com this.
Pedido.java
public class Pedido {
    private Cliente cliente;

    public Pedido(Cliente cliente) {
        this.cliente = cliente;
    }
}
flowchart LR
    A["new Cliente(...) "] -->|referência| B["new Pedido(cliente)"]

3 · Exemplo 1 · Código

Pedido associado a Cliente

03

Problema: um pedido registra seu número e o cliente responsável. O pedido mantém a referência ao cliente recebido na criação.

Cliente.java
public class Cliente {
    private String nome;
    private String email;

    public Cliente(String nome, String email) {
        this.nome = nome;
        this.email = email;
    }

    public String getNome() { return nome; }
    public String getEmail() { return email; }
}
Pedido.java
public class Pedido {
    private int numero;
    private Cliente cliente;

    public Pedido(int numero, Cliente cliente) {
        this.numero = numero;
        this.cliente = cliente;
    }

    public void exibirResumo() {
        System.out.println("Pedido: " + numero);
        System.out.println("Cliente: " + cliente.getNome());
        System.out.println("E-mail: " + cliente.getEmail());
    }
}

5 · Exemplo 1 · Criação

Instanciar e passar a referência

05
ProgramaPedido.java
public class ProgramaPedido {
    public static void main(String[] args) {
        Cliente cliente = new Cliente(
            "Ana Souza", "ana@email.com"
        );

        // Passa a referência de cliente
        Pedido pedido = new Pedido(101, cliente);

        pedido.exibirResumo();
    }
}

Passo a passo

  1. new Cliente(...) cria a instância.
  2. cliente guarda a referência para ela.
  3. Essa referência é argumento de new Pedido(101, cliente).
  4. O construtor guarda-a em this.cliente.
  5. Pedido usa o objeto associado para obter nome e e-mail.

6 · Exemplo 2 · Código

Disciplina associada a Professor

06

Problema: cada disciplina registra código e nome, além de uma referência ao professor responsável. Ao mostrar seus dados, consulta o nome e a área do professor.

Professor.java
public class Professor {
    private String nome;
    private String area;

    public Professor(String nome, String area) {
        this.nome = nome;
        this.area = area;
    }

    public String getNome() { return nome; }
    public String getArea() { return area; }
}
Disciplina.java
public class Disciplina {
    private String codigo;
    private String nome;
    private Professor professor;

    public Disciplina(String codigo, String nome,
                      Professor professor) {
        this.codigo = codigo;
        this.nome = nome;
        this.professor = professor;
    }

    public void exibirDados() {
        System.out.println(codigo + " - " + nome);
        System.out.println("Professor: " + professor.getNome());
        System.out.println("Área: " + professor.getArea());
    }
}

ProgramaDisciplina.java
public class ProgramaDisciplina {
    public static void main(String[] args) {
        Professor professora = new Professor(
            "Marina Costa", "Programação"
        );

        Disciplina poo = new Disciplina(
            "POO2", "Programação Orientada a Objetos",
            professora
        );

        poo.exibirDados();
    }
}
Observe: a instância professora é criada antes; sua referência é passada ao construtor de Disciplina.
8 · Síntese

O que a associação permite

08
Campo

Tipo de outra classe

private Professor professor; declara uma referência para uma instância Professor.

Construtor

Recebe o objeto

O parâmetro do tipo Professor deixa o programa fornecer a instância associada.

Uso

Acessa comportamento

Pelo campo, a classe pode chamar métodos públicos do objeto associado, como professor.getNome().

Nos exemplos: a instância associada é criada antes e o construtor recebe uma referência válida. Tratamento de null pode ser visto em outra aula.
9 · Exercício não resolvido

Reservas de quartos em uma pousada

09

Uma pousada deseja cadastrar reservas. Cada Reserva possui código, data de entrada e data de saída. Toda reserva pertence a um único Cliente e ocupa um único Quarto. Cliente possui nome e telefone. Quarto possui número, tipo e valor da diária.

Defina as três classes com atributos privados. A classe Reserva deve manter referências para um objeto Cliente e um objeto Quarto. Receba as duas referências no construtor de Reserva e guarde-as nos campos correspondentes.

No programa principal, crie primeiro um cliente e um quarto; em seguida, crie uma reserva passando as referências desses objetos. Exiba os dados da reserva, incluindo nome do cliente, número e tipo do quarto e valor da diária.

Regras: um cliente pode fazer várias reservas e um quarto pode aparecer em várias reservas ao longo do tempo. Nesta versão, não implemente disponibilidade, cancelamento nem persistência.
