1 · Continuidade

O ponto de partida da aula anterior

01
Classe

Modelo do domínio

Define atributos e métodos. É o projeto que descreve quais dados um objeto terá e quais mensagens ele poderá receber.

Objeto

Instância em execução

Tem identidade, estado próprio e comportamento. Dois objetos da mesma classe podem ter valores totalmente diferentes.

Encapsulamento

Estado protegido

Atributos ficam privados e as alterações passam por métodos públicos. A classe decide quais mudanças são válidas.

Ideia central: se o atributo é privado, o mundo externo não altera o objeto diretamente. Ele pede ao objeto que execute um método.
2 · Problema

Encapsular cria uma nova pergunta

02

Se os atributos são privados, como inicializar e alterar o objeto corretamente?

Resposta da aula: construtores definem o nascimento do objeto; getters e setters controlam leitura e alteração; sobrecarga cria alternativas de uso sem perder clareza.

3 · Construtores

Como o objeto nasce

03

O que é

Construtor é um bloco especial executado no momento do new. Ele prepara o estado inicial do objeto.

  • Tem o mesmo nome da classe.
  • Não possui tipo de retorno.
  • Pode receber parâmetros.
  • Pode validar dados antes de gravar nos atributos.
Exemplo mínimo
public class Aluno {
    private String nome;
    private double media;

    public Aluno(String nome, double media) {
        setNome(nome);
        setMedia(media);
    }
}
Boa prática: quando a validação já existe no setter, o construtor pode chamar o setter para evitar regras duplicadas.

5 · Sobrecarga

O mesmo nome, diferentes assinaturas

05

Sobrecarga acontece quando uma classe possui métodos ou construtores com o mesmo nome, mas listas de parâmetros diferentes.

Assinatura considera o nome do método e os tipos/quantidade/ordem dos parâmetros. O tipo de retorno sozinho não diferencia sobrecarga.

Sobrecarga de método
public void depositar(double valor) { ... }

public void depositar(double valor, String descricao) { ... }

public void depositar(double valor, String descricao,
                      boolean emitirComprovante) { ... }
Atenção: sobrecarga não é criar vários métodos quase iguais por falta de organização. Ela é útil quando as variações representam formas naturais de executar a mesma operação.
6 · Sobrecarga de construtores

Formas diferentes de criar o mesmo tipo de objeto

06
Classe com construtores sobrecarregados
public class Cliente {
    private String nome;
    private String cpf;
    private boolean ativo;

    public Cliente() {
        this("Sem nome", "Não informado", true);
    }

    public Cliente(String nome) {
        this(nome, "Não informado", true);
    }

    public Cliente(String nome, String cpf, boolean ativo) {
        setNome(nome);
        setCpf(cpf);
        this.ativo = ativo;
    }
}

O papel do this(...)

Um construtor pode chamar outro construtor da mesma classe. Isso concentra a inicialização completa em um único lugar.

  • Evita repetição de código.
  • Facilita manutenção das regras de criação.
  • Deve ser a primeira instrução do construtor.

8 · Contexto 1

Conta bancária simplificada

08

Domínio: uma instituição precisa representar contas bancárias. Cada conta tem número, titular, saldo e limite. O saldo não deve ser alterado diretamente: depósitos, saques e alterações de limite precisam passar por métodos públicos com validação.

Especificação da classe

  • Classe: ContaBancaria
  • Atributos privados: numero, titular, saldo, limite
  • Construtores: padrão, com número/titular, completo
  • Getters: número, titular, saldo, limite
  • Setters: titular e limite com validação
  • Métodos: depósitos e saques sobrecarregados

Regras de negócio

  • Número da conta não deve ser vazio.
  • Titular não deve ser vazio.
  • Saldo inicial não pode ser negativo.
  • Limite não pode ser negativo.
  • Saque só ocorre se houver saldo + limite disponível.
  • Depósito só ocorre com valor positivo.

ContaBancaria.java

12
ContaBancaria.java
public class ContaBancaria {
    private String numero;
    private String titular;
    private double saldo;
    private double limite;

    public ContaBancaria() {
        this("000", "Sem titular", 0, 0);
    }

    public ContaBancaria(String numero, String titular) {
        this(numero, titular, 0, 0);
    }

    public ContaBancaria(String numero, String titular,
                         double saldoInicial, double limite) {
        setNumero(numero);
        setTitular(titular);
        setLimite(limite);
        if (saldoInicial >= 0) {
            this.saldo = saldoInicial;
        }
    }

    private void setNumero(String numero) {
        if (numero != null && !numero.isBlank()) {
            this.numero = numero;
        }
    }

    public String getNumero() { return numero; }
    public String getTitular() { return titular; }
    public double getSaldo() { return saldo; }
    public double getLimite() { return limite; }

    public void setTitular(String titular) {
        if (titular != null && !titular.isBlank()) {
            this.titular = titular;
        }
    }

    public void setLimite(double limite) {
        if (limite >= 0) {
            this.limite = limite;
        }
    }

    public void depositar(double valor) {
        depositar(valor, "Depósito comum");
    }

    public void depositar(double valor, String descricao) {
        if (valor > 0) {
            saldo += valor;
            System.out.println(descricao + ": +" + valor);
        }
    }

    public boolean sacar(double valor) {
        return sacar(valor, "Saque comum");
    }

    public boolean sacar(double valor, String descricao) {
        if (valor > 0 && valor <= saldo + limite) {
            saldo -= valor;
            System.out.println(descricao + ": -" + valor);
            return true;
        }
        System.out.println("Saque recusado: " + descricao);
        return false;
    }

    public void exibirResumo() {
        System.out.println(numero + " | " + titular +
                " | saldo=" + saldo + " | limite=" + limite);
    }
}

public class ProgramaConta {
    public static void main(String[] args) {
        ContaBancaria contaAna =
                new ContaBancaria("001", "Ana", 500, 200);

        ContaBancaria contaBruno =

        contaAna.sacar(100);
        contaAna.setLimite(300);

        contaBruno.depositar(900);
        contaBruno.sacar(1200, "Compra de notebook");

        contaAna.exibirResumo();
        contaBruno.exibirResumo();
    }
}

O que observar

  • O objeto nasce pelo construtor escolhido.
  • depositar tem duas versões.
  • sacar tem duas versões.
  • O saldo não tem setter público: muda por depósito e saque.
  • O limite tem setter porque alterar limite é uma operação permitida.
14 · Contexto 2

Produto em estoque

14

Domínio: uma loja precisa controlar produtos. Cada produto possui código, nome, preço e quantidade em estoque. O preço e o estoque não podem receber valores inválidos, e as operações de venda/reposição devem refletir ações reais do negócio.

Especificação da classe

  • Classe: Produto
  • Atributos privados: codigo, nome, preco, quantidadeEstoque
  • Construtores: padrão, com código/nome, completo
  • Getters: todos os atributos
  • Setters: nome e preço com validação
  • Métodos: vender e repor sobrecarregados

Regras de negócio

  • Código e nome não devem ser vazios.
  • Preço não pode ser negativo.
  • Estoque não pode ser negativo.
  • Venda exige quantidade positiva e estoque suficiente.
  • Reposição exige quantidade positiva.
  • Venda promocional usa desconto entre 0 e 50%.

18 · Código resolvido

Produto.java

18
Produto.java
public class Produto {
    private String codigo;
    private String nome;
    private double preco;
    private int quantidadeEstoque;

    public Produto() {
        this("SEM-CODIGO", "Produto sem nome", 0, 0);
    }

    public Produto(String codigo, String nome) {
        this(codigo, nome, 0, 0);
    }

    public Produto(String codigo, String nome,
                   double preco, int quantidadeEstoque) {
        setCodigo(codigo);
        setNome(nome);
        setPreco(preco);
        if (quantidadeEstoque >= 0) {
            this.quantidadeEstoque = quantidadeEstoque;
        }
    }

    private void setCodigo(String codigo) {
        if (codigo != null && !codigo.isBlank()) {
            this.codigo = codigo;
        }
    }

    public String getCodigo() { return codigo; }
    public String getNome() { return nome; }
    public double getPreco() { return preco; }
    public int getQuantidadeEstoque() { return quantidadeEstoque; }

    public void setNome(String nome) {
        if (nome != null && !nome.isBlank()) {
            this.nome = nome;
        }
    }

    public void setPreco(double preco) {
        if (preco >= 0) {
            this.preco = preco;
        }
    }

    public void repor(int quantidade) {
        repor(quantidade, "Reposição comum");
    }

    public void repor(int quantidade, String motivo) {
        if (quantidade > 0) {
            quantidadeEstoque += quantidade;
            System.out.println(motivo + ": +" + quantidade);
        }
    }

    public boolean vender(int quantidade) {
        return vender(quantidade, 0);
    }

    public boolean vender(int quantidade, double desconto) {
        if (quantidade <= 0 || quantidade > quantidadeEstoque) {
            System.out.println("Venda recusada para " + nome);
            return false;
        }

        if (desconto < 0 || desconto > 0.50) {
            System.out.println("Desconto inválido para " + nome);
            return false;
        }

        quantidadeEstoque -= quantidade;
        double total = quantidade * preco * (1 - desconto);
        System.out.println("Venda de " + nome + ": R$ " + total);
        return true;
    }

    public double calcularValorEstoque() {
        return preco * quantidadeEstoque;
    }

    public void exibirDados() {
        System.out.println(codigo + " | " + nome +
                " | preço=" + preco +
                " | estoque=" + quantidadeEstoque +
                " | total=" + calcularValorEstoque());
    }
}

public class ProgramaProduto {
    public static void main(String[] args) {
        Produto mouse =
                new Produto("P001", "Mouse", 80, 12);

        Produto teclado =
                new Produto("P002", "Teclado");

        mouse.vender(3);
        mouse.repor(10, "Compra do fornecedor");
        mouse.setPreco(75);

        teclado.setPreco(160);
        teclado.repor(5);
        teclado.vender(2, 0.10);

        mouse.exibirDados();
        teclado.exibirDados();
    }
}

O que observar

  • O construtor completo cria objeto pronto para uso.
  • O construtor com dois parâmetros cria objeto parcialmente configurado.
  • repor tem versão simples e versão com motivo.
  • vender tem versão comum e versão com desconto.
  • Estoque não tem setter público porque deve mudar por venda ou reposição.

21 · Erros comuns

O que evitar

21

Setter para tudo

Nem todo atributo precisa de setter público. Saldo, estoque e média final costumam mudar por métodos de negócio.

Construtor vazio sem sentido

Se o objeto não consegue operar sem dados obrigatórios, prefira exigir esses dados no construtor.

Sobrecarga confusa

Evite versões que deixam ambíguo o significado dos parâmetros. Nomes claros e tipos adequados importam.

Validação duplicada

Se setter e construtor validam a mesma regra em lugares diferentes, o código tende a ficar inconsistente.

Atributo público

Expor atributo permite alteração sem regra. Isso quebra encapsulamento e dificulta manutenção.

Retorno ignorado

Métodos como sacar e vender retornam boolean para informar sucesso ou falha.
