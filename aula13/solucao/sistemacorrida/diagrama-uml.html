Sistema de Corrida

Diagramas UML baseados nas classes e nos objetos criados em Main.java.

Diagrama de classes

Uma corrida referencia um corredor e um trajeto por associações. O resultado é criado dentro de Corrida e representa composição.

classDiagram
    class Corredor {
        -String nome
        -String rg
        +Corredor(String nome, String rg)
        +getNome() String
        +setNome(String nome) void
        +getRg() String
        +setRg(String rg) void
    }
    class Trajeto {
        -String nome
        -double distancia
        -String local
        +Trajeto(String nome, double distancia, String local)
        +getNome() String
        +setNome(String nome) void
        +getDistancia() double
        +setDistancia(double distancia) void
        +getLocal() String
        +setLocal(String local) void
    }
    class Corrida {
        -Corredor corr
        -Trajeto traj
        -Resultado res
        -String data
        -String horario
        +Corrida(Corredor corr, Trajeto traj, String tempoFinal, String situacao, String data, String horario)
        +getCorr() Corredor
        +setCorr(Corredor corr) void
        +getTraj() Trajeto
        +setTraj(Trajeto traj) void
        +getRes() Resultado
        +setRes(Resultado res) void
        +getData() String
        +setData(String data) void
        +getHorario() String
        +setHorario(String horario) void
    }
    class Resultado {
        -String tempoFinal
        -String situacao
        +Resultado(String tempoFinal, String situacao)
        +getTempoFinal() String
        +setTempoFinal(String tempoFinal) void
        +getSituacao() String
        +setSituacao(String situacao) void
    }
    Corrida "0..*" --> "1" Corredor : associa
    Corrida "0..*" --> "1" Trajeto : associa
    Corrida "1" *-- "1" Resultado : compõe

Cada instância de Corrida mantém exatamente um corredor, um trajeto e um resultado; um corredor ou trajeto pode ser referenciado por várias corridas.

Diagrama de objetos

Estado ilustrado para as duas corridas construídas no método main. O corredor co é compartilhado; cada corrida tem seu próprio trajeto e resultado.

classDiagram
    class co_Corredor["co : Corredor<<instância>>"] {
        nome = Pedro Sousa
        rg = abc-123
    }
    class tr_Trajeto["tr : Trajeto<<instância>>"] {
        nome = Pista Circular
        distancia = 200
        local = Campo Maior
    }
    class tr2_Trajeto["tr2 : Trajeto<<instância>>"] {
        nome = Pista com declive
        distancia = 100
        local = Teresina
    }
    class cr_Corrida["cr : Corrida<<instância>>"] {
        data = 22/05/2026
        horario = 10h20m
    }
    class cr2_Corrida["cr_2 : Corrida<<instância>>"] {
        data = 10/11/2026
        horario = 09h30m
    }
    class res1_Resultado["res : Resultado (de cr)<<instância>>"] {
        tempoFinal = 10min30s
        situacao = Concluído
    }
    class res2_Resultado["res : Resultado (de cr_2)<<instância>>"] {
        tempoFinal = 20min30s
        situacao = Pendente
    }
    cr_Corrida --> co_Corredor : corr
    cr_Corrida --> tr_Trajeto : traj
    cr_Corrida *-- res1_Resultado : res
    cr2_Corrida --> co_Corredor : corr
    cr2_Corrida --> tr2_Trajeto : traj
    cr2_Corrida *-- res2_Resultado : res

Os identificadores res aparecem em cada objeto Corrida; foram diferenciados no desenho para deixar claro que são dois objetos distintos.
