Agregação · 1. UML

Compra, cliente, produto e datas

Compra recebe referências a Cliente e Produto já criados. Cliente e Produto também recebem objetos Data. O diamante aberto fica no todo que mantém a referência agregada.

O construtor de Compra recebe cli e prod. O construtor de Cliente e Produto recebe uma Data já instanciada. O desenho mostra os campos de referência usados no código.
Leitura do código: a existência de Compra não cria Cliente nem Produto. O programa instancia esses objetos antes e os entrega ao construtor de Compra.

Compra.java
package compras.agregacao;

public class Compra {
    private Cliente cli;
    private Produto prod;
    private int quant;
    private double total;

    public Compra(Cliente cli, Produto prod, int quant) {
        this.cli = cli;
        this.prod = prod;
        this.quant = quant;
        this.total = this.quant * prod.getPreco();
    }

    public Cliente getCli() { return cli; }
    public void setCli(Cliente cli) { this.cli = cli; }
    public Produto getProd() { return prod; }
    public void setProd(Produto prod) { this.prod = prod; }
    public int getQuant() { return quant; }
    public void setQuant(int quant) { this.quant = quant; }
    public double getTotal() { return total; }
    public void setTotal(double total) { this.total = total; }
}
Observe o cálculo: total é calculado no construtor. Se depois forem alterados o produto, a quantidade ou o preço, esse valor não é recalculado automaticamente.

Agregação · 4. Main

Criação e uso dos objetos

TesteAgregacao.java
package compras.agregacao;

public class TesteAgregacao {
    public static void main(String[] args) {
        Data dt1 = new Data(10, 1, 2002);
        Data dt2 = new Data(2, 1, 1990);

        Produto p1 = new Produto("Arroz", 2.5, dt1);
        Cliente cl1 = new Cliente("José", 28, dt2);

        Compra cp = new Compra(cl1, p1, 5);

        System.out.println("Informações da Compra:");
        System.out.println("Nome do cliente: " + cp.getCli().getNome());
        System.out.println("Idade do cliente: " + cp.getCli().getIdade());
        int dia = cp.getCli().getDtNasc().getDia();
        int mes = cp.getCli().getDtNasc().getMes();
        int ano = cp.getCli().getDtNasc().getAno();
        System.out.println("Data de Nascimento do cliente: "
                + dia + "/" + mes + "/" + ano);

        System.out.println("Nome do produto: " + cp.getProd().getNome());
        System.out.println("Quantidade: " + cp.getQuant());
        dia = cp.getProd().getValidade().getDia();
        mes = cp.getProd().getValidade().getMes();
        ano = cp.getProd().getValidade().getAno();
        System.out.println("Data de Validade do produto: "
                + dia + "/" + mes + "/" + ano);

        System.out.println("Valor total da compra: " + cp.getTotal());
    }
}

1 · Datas

dt1 e dt2 são criadas antes dos objetos que as recebem.

2 · Produto e cliente

p1 recebe dt1; cl1 recebe dt2.

3 · Compra

cp recebe as referências cl1 e p1, além da quantidade 5.

Composição · 1. UML

Pedido e ItemProduto

Pedido cria seu ItemProduto dentro do construtor. O item é parte do pedido e o losango preenchido marca a composição.

    Pedido "1" *-- "1" ItemProduto : item
O construtor de Pedido instancia ItemProduto com os dados recebidos e calcula valor a partir da quantidade e do preço.
Detalhe do pacote: a classe também declara setItem, que permite trocar a referência depois da construção. O construtor expressa a composição; esse setter deixa a substituição da parte disponível no código.

Pedido.java
package compras.composicao;

public class Pedido {
    private ItemProduto item;
    private double valor;

    public Pedido(String nome, int quant, double preco) {
        this.item = new ItemProduto(nome, quant, preco);
        this.valor = item.getQuant() * item.getPreco();
    }

    public ItemProduto getItem() { return item; }
    public void setItem(ItemProduto item) { this.item = item; }
    public double getValor() { return valor; }
    public void setValor(double valor) { this.valor = valor; }
}
A linha this.item = new ItemProduto(nome, quant, preco); é o ponto central: o próprio Pedido cria o objeto que mantém como parte.

Composição · 4. Main

Criação e consulta do objeto composto

TesteComposicao.java
package compras.composicao;

public class TesteComposicao {
    public static void main(String[] args) {
        Pedido pedido = new Pedido("Arroz", 4, 2.5);

        System.out.println("Valor total do pedido: " + pedido.getValor());
        System.out.println("Nome do produto: " + pedido.getItem().getNome());
        System.out.println("Preço do produto: " + pedido.getItem().getPreco());
        System.out.println("Quantidade do produto: " + pedido.getItem().getQuant());
    }
}
Sequência: o main cria Pedido; o construtor de Pedido cria ItemProduto; depois, o programa consulta os dados do item por pedido.getItem().
